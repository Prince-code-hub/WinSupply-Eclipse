# Bookish API Routes

### GET methods

#### Book Entity

- All books
- Book by bookId
- Books by genreId

#### Genre Entity

- All genres
- Genre by genreId

#### Review Entity

- All reviews
- Review by reviewID
- Reviews by genreID
- Reviews filtered by datePosted

#### Comment Entity

- All comments
- Comment by commentId
- Comments by reviewId

### POST methods

#### Review Entity

- New review

#### Comment Entity

- New comment
